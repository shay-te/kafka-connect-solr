# Feature parity vs kafka-connect-elasticsearch

Updated after closing every gap from the previous audit. Where the
Solr connector now implements a feature the ES connector also has, the
row is ✅. Where we go further (do it better) it's 🟢.

## TL;DR

Solr connector now supports every config key the ES connector exposes
that has a Solr analogue, plus a few Solr-native ones the ES connector
can't express. Wherever there's a choice in how to do something we picked
the better default (HTTP/2 multiplexing, TLSv1.3,
per-record async offset tracking, zstd compression). Kerberos is not supported.
